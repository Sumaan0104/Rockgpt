Pipeline & Engine

How RockGPT Works – AI Assistant

Behind RockGPT's minimalist interface lies an orchestrated AI pipeline optimized for real-time inference, token-by-token streaming, and robust user safety.

The 5-Stage Execution Lifecycle

1

Multimodal Prompt Ingestion

When you submit a query, RockGPT processes both text and optional attachments (images, code files, or text documents). Attachments are safely encoded and combined with your query into a structured payload.

2

Context Window Assembly & Privacy Sanitization

The application assembles conversation history so the assistant maintains conversational context across replies. All payloads pass through client-side and server-side validation to ensure integrity and prevent injection.

3

Real-Time Inference & SSE Streaming

Rather than waiting for the complete response to generate in a black box, RockGPT establishes a Server-Sent Events (SSE) stream. Tokens are pushed to your screen within milliseconds of neural computation.

4

Progressive Markdown & Syntax Rendering

Incoming tokens are parsed in real time into GitHub-flavored Markdown. Code blocks receive immediate syntax highlighting, tables format dynamically, and mathematical formulas align cleanly.

5

Secure Local & Cloud Persistence

Conversations are stored reliably. Free tier users enjoy instant local storage without required registration, while signed-in members have encrypted cloud synchronization with optional two-factor authentication (2FA).
